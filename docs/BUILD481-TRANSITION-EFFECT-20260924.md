## 门禁边界

`native_resources=false` 总门禁保持不变；只有上述两个资源 key 及已验的六种
几何蒙版经精确 ID、缓存路径、tree hash、逐文件内容与材料绑定门禁通过。
其他转场、特效、滤镜、在线模板和未验资源仍拒绝。叠化可能让两段源音频
在重叠区相加，实际项目应听查成片；本次可解码与测试画面不代表任意素材
组合、其他会员等级或所有输出参数均已验收。
